# Gemini AI Chatbot

A simple AI chatbot built using **Python** and the **Google Gemini API**.
The chatbot allows users to enter questions and receive AI-generated responses.

## Features

* AI-powered chat using Gemini API
* Simple and user-friendly interface
* Accepts user questions and provides responses
* Built using Python
* Easy to run and modify

## Technologies Used

* Python
* Google Gemini API
* Google Colab

## How to Run

1. Open the project in Google Colab.
2. Add your Gemini API key securely.
3. Run the Python code.
4. Enter your question.
5. The chatbot will generate an AI response.

## Project Purpose

This project was created to understand how **Generative AI and APIs** can be integrated into a Python application and to gain practical experience with AI chatbot development.
